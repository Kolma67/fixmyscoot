Shorts factory uploader – Privacy Policy

Last updated: 8 November 2026

"Shorts factory" (the uploader) is a private desktop tool run by Krisztián Kolma, the operator of fixmyscoot.hu. It uploads short videos that the operator produces to the operator's own YouTube, TikTok and Instagram accounts. It is not offered to the public.

What data the uploader accesses

  • YouTube (Google) data: with your permission the uploader uses the scopes youtube.upload (to upload videos and set their title, description, tags and publish time) and youtube.readonly (to read the connected channel's name and ID).
  • TikTok and Instagram: an access token for the connected account and the account's name/ID, used only to publish videos.

How the data is used and stored

  • Access tokens and channel IDs are stored only on the operator's own computer, in a local database. They are never sent to any server other than the platform they belong to (Google/YouTube, TikTok or Meta).
  • The data is used only to upload videos and record where each video was posted.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

The uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The uploader uses the YouTube API Services, so the YouTube Terms of Service and the Google Privacy Policy also apply.

Removing access and deleting data

You can revoke the uploader's access at any time at myaccount.google.com/permissions. Removing an account inside the uploader deletes its stored token from the local database.
